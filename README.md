## Тема

Информационная система автоматизации анализа кредитных рисков в подсистеме управления кредитным портфелем АО «ТБанк».

## Стек

- Vue 3
- Vue Router
- ASP.NET Core
- PostgreSQL

## Запуск клиентской части

Требуется установленный Node.js LTS.

Из корневой папки проекта выполните:

```bash
cd frontend
npm install
npm run dev
```

Откройте адрес, который покажет Vite. По умолчанию это http://localhost:5173.

Основные страницы:

- `/` — список кредитных заявок;
- `/new` — создание заявки;
- `/login` — вход в систему.

На текущем этапе данные хранятся в памяти приложения. Сервер и база данных пока не подключены.
