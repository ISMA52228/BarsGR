# Лабораторная работа 4. Компоненты и маршруты Vue

**Проект:** BarsGR  
**Тема:** Информационная система автоматизации анализа кредитных рисков в подсистеме управления кредитным портфелем АО «ТБанк»

## Выполненная работа

В клиентской части приложения подключён Vue Router. Для экранов списка заявок, создания заявки и входа настроены отдельные маршруты:

- `/` — список кредитных заявок;
- `/new` — создание кредитной заявки;
- `/login` — вход в систему.

Общая шапка вынесена в компонент `AppHeader.vue` и отображается вне `router-view`. Таблица вынесена в `TicketTable.vue` и получает список заявок через обязательный prop `items`.

Общий реактивный массив находится в `src/ticketsStore.js`. Страница создания добавляет новую запись в этот массив. Данные существуют только в памяти приложения и не сохраняются после перезагрузки страницы.

## Структура клиентской части

```text
frontend/src/

```
